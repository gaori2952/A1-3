# AI 코딩 도구 사용 기록

도구: Codex. 아래는 실제 작업 대화와 변경 내용을 요약한 기록입니다. 

## 요구사항 정의
사용자는 A1-3 기존 코드에 실제 AI API 기능, 반응형 검증, README, 기획서와 증빙이 필요하다는 과제 원문을 제공했습니다. 코드를 새로 복제하지 않고 ProjectFlow의 목적과 구성에 맞춰 보완하기로 했습니다.

## 오류 발견과 수정
1. 새 Vercel 배포는 성공했지만 홈페이지가 API 경로 오류 JSON을 표시했습니다.
2. Python 진입점이 홈페이지 요청까지 처리하는데 정적 페이지 응답이 없는 것이 원인이었습니다.
3. 허용된 HTML·CSS·JS만 제공하도록 수정하고 비밀 파일·경로 우회는 차단했습니다.
4. 새 배포에서 로그인·대시보드·프로젝트 생성과 분석 화면을 확인했습니다.

## AI 기능 개선
사용자는 시작 플랜이 모든 프로젝트에서 같은 작업을 반복하고 체크박스와 설명이 붙어 보이는 스크린샷을 제시했습니다. 기존 고정 추천과 조용한 데모 대체 처리를 제거하고, 목표를 실제 모델에 전달하며 결과를 선택 카드로 표시하도록 개선했습니다.

## 제공자 선택
사용자는 copa.codyssey.kr/v1/chat/completions, Bearer 가상 키, gpt-5-mini 예시를 제공하고 이 제공자로 연동하겠다고 명시했습니다. 이에 맞춰 서버에서 messages를 전달하고 choices의 content를 파싱하도록 구현했습니다.

## 검증 방식
외부 API mock 테스트와 실제 배포 화면 검증을 구분합니다. 테스트 통과를 실제 모델 호출 성공으로 주장하지 않습니다. 실제 키는 Vercel 환경변수에만 설정하며 대화·증빙에는 포함하지 않습니다.

## 원문 증빙
제출 패키지에는 키가 없는 실제 대화 부분과 시작 플랜 개선 요청 스크린샷을 함께 포함합니다. 코드 변경은 GitHub 커밋 이력으로 확인할 수 있습니다.
