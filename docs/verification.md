# 검증 및 제출 현황

## 자동 검증
- Python unittest 21개 통과: API 라우팅, Canvas 기존 동작, 실제 AI 입력·출력 계약, 인증·쿼터·타임아웃·잘못된 JSON 처리.
- insights.js, dashboard.js JavaScript 문법 확인 통과.
- 이 결과는 외부 API mock 검증입니다.

## 배포 검증
최종 배포 후 페이지 이동, 모바일·데스크톱 레이아웃과 빈 질문·API 실패 안내를 확인합니다.
실제 Codyssey 가상 키로 성공한 분석과 시작 플랜은 환경변수 설정 후 별도로 검증합니다.
