# ProjectFlow 서비스 기획서

## 1. 서비스 목적
개인 프로젝트의 목표·작업·이슈를 한곳에서 관리하고, AI가 실행할 날짜와 다음 행동을 제안하도록 합니다. 기록된 작업을 일정과 연결해 무엇을 언제 해야 하는지 확인할 수 있게 돕습니다.

## 2. 타겟 사용자
- 과제·시험 준비·개인 프로젝트를 동시에 진행하는 학생
- 별도 프로젝트 관리 도구 없이 작업을 관리하려는 1인 제작자
- 목표는 정했지만 실행 일정을 잡기 어려운 사용자

## 3. 페이지와 이동
| 페이지 | 핵심 기능 | 이동 |
| --- | --- | --- |
| 로그인 | 데모 진입 | 대시보드 |
| 대시보드 | 프로젝트 생성·AI 일정·오늘 할 일·2주 달력 | 프로젝트 카드, 공통 메뉴 |
| 프로젝트 | 작업·이슈·진행률 | AI 분석, 전체 프로젝트 |
| AI 인사이트 | 질문과 분석 결과 | 프로젝트 돌아가기 |
| 보관함 | 완료 작업·완료 프로젝트 | 원래 프로젝트 |
| 설정 | 프로젝트 유형, Canvas 선택 학기 | 공통 메뉴 |

데스크톱은 사이드 메뉴, 모바일은 상단 메뉴를 사용합니다. 좁은 화면의 달력은 내부 스크롤을 허용합니다.

## 4. 핵심 기능
프로젝트 생성, 날짜별 작업 확인, 작업 완료 처리, 이슈 기록, AI 일정 추천, AI 프로젝트 분석, 완료 이력 확인을 제공합니다. 완료한 작업은 보관함에 표시되며, 작업이 하나 이상이고 모두 완료된 프로젝트는 기존 상태값이 active여도 보관함에 표시합니다. 빈 프로젝트나 단순히 마감일이 지난 작업은 완료로 분류하지 않습니다.

## 5. AI 기능 설계
### AI 일정 추천
- 입력: 프로젝트 이름·목표·유형·시작일·마감일·추가 설명.
- 필수값: 이름과 목표.
- 기준: 마감일이 없으면 시작일부터 7일. 마감일이 시작일보다 이르면 입력 오류 안내.
- 출력: 최대 3개의 실행 일정. 각 항목은 제목·날짜·15~180분 소요 시간·우선순위·배치 이유를 포함.
- 저장: 사용자가 선택한 항목만 작업으로 추가하며 추천 날짜를 예정일에 반영.
- 가치: 사용자가 정한 목표를 실행할 수 있는 날짜와 시간 제안. 공부할 과목·교재·단원을 대신 선택하지 않음.

### AI 프로젝트 분석
- 입력: 목표·마감일·완료 및 남은 작업·열린 이슈·질문.
- 출력: summary, status, next_steps, risks.
- 다음 작업과 위험 대응은 각각 최대 3개.
- 가치: 프로젝트 상황을 다시 입력하지 않고 다음 우선순위와 대응 방향 확인.

Python이 Codyssey Chat Completions API를 호출하고 JSON 필드·우선순위·날짜·소요 시간을 검증합니다. JavaScript는 검증된 응답을 화면에 표시합니다.

## 6. 실패 처리 기준
| 상황 | 처리 |
| --- | --- |
| 필수값 누락 | 요청 전 입력 안내 |
| 잘못된 날짜·입력 범위 초과 | 400 안내, 모델 호출하지 않음 |
| 키 미설정·인증 실패 | 연결 설정 안내 |
| 429 | 사용 한도 안내 |
| 5xx·네트워크 오류 | 다시 시도 안내 |
| 응답 지연·타임아웃 | 처리 중 표시, 시간 초과 안내 |
| 잘못된 생성 JSON | 결과 형식 오류 안내 |

질문은 1,000자, 작업·이슈는 각각 50개, 요청 본문은 64KB로 제한합니다. 프론트 타임아웃은 55초, AI 서버 응답 제한은 40초입니다. 중복 클릭을 막고 자동 재시도는 하지 않습니다. AI 분석 완료 후 5초 간격을 둡니다.

## 7. 선택 기능: Canvas
성균관대학교 Canvas에서 연도·학기를 선택해 해당 과목의 과제를 조회합니다. Canvas API 토큰은 서버 환경 변수로 관리하며 개인 연동 코드 검증 후 조회합니다. 선택한 과제만 과목별 프로젝트와 작업으로 저장합니다. 중복 과제는 다시 추가하지 않습니다. 실제 개인 과제 조회는 운영자 설정 후 확인해야 합니다.

## 8. 구현 범위와 운영
프론트는 순수 HTML/CSS/JavaScript, 백엔드는 Vercel Python입니다. 데이터는 localStorage에 저장하는 학습용 데모이며, 실제 계정 인증과 기기 간 동기화는 향후 확장 범위입니다.

AI 키와 Canvas 토큰은 환경 변수로 관리합니다. 모델 응답 전체·인증 헤더·키를 로그나 안내에 노출하지 않습니다. 비용과 쿼터는 제공자에서 관리하며 공개 API의 서버 전체 요청 제한은 향후 운영 고도화 범위입니다.

## 9. 성공 기준
동료가 공개 URL의 데모로 진입하고 3개 이상의 페이지를 이동하며, 목표와 질문을 입력해 실제 AI 응답을 확인할 수 있어야 합니다. 모바일과 데스크톱에서 핵심 입력·버튼·결과가 표시되어야 합니다. README·기획서·데스크톱/모바일/AI 스크린샷·AI 코딩 기록을 저장소에서 확인할 수 있어야 합니다.
