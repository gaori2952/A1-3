# ProjectFlow 서비스 기획서

## 목적과 타겟
개인 프로젝트를 진행하는 학생과 1인 제작자가 목표를 실제 작업으로 나누고, 막힌 문제와 다음 행동을 한 화면에서 확인하도록 돕습니다. 단순한 할 일 기록에서 나아가 프로젝트 맥락을 사용하는 AI 제안을 제공합니다.

## 페이지와 이동
| 페이지 | 핵심 기능 | 이동 |
| --- | --- | --- |
| 로그인 | 데모 진입 | 대시보드 |
| 대시보드 | 프로젝트 생성·오늘 할 일·2주 일정 | 프로젝트 카드·상단/모바일 메뉴 |
| 프로젝트 | 작업·우선순위·이슈·진행률 | AI 인사이트·전체 프로젝트 |
| AI 인사이트 | 질문·상황 요약·행동·위험 | 프로젝트 돌아가기 |
| 설정·보관함 | 일정 설정·완료 프로젝트 | 공통 메뉴 |

데스크톱에서는 사이드 메뉴, 모바일에서는 상단 메뉴를 사용합니다. 달력은 좁은 화면에서 내부 가로 스크롤을 허용하고 페이지 전체가 넘치지 않도록 확인합니다.

## AI 기능 1: 시작 플랜
- 입력: 이름, 유형, 목표, 마감일, 추가 설명.
- 처리: Python이 Codyssey OpenAI 호환 Chat Completions API를 호출.
- 출력: 목표에 맞는 첫 작업 최대 3개, 우선순위, 제안 이유.
- 가치: 시작하기 어려운 큰 목표를 실행 단위로 분해.
- 선택한 항목만 브라우저 저장소에 추가.
- 실패: 오류 메시지를 표시하고 다시 시도 또는 빈 프로젝트로 시작할 수 있도록 제공. 템플릿으로 성공을 위장하지 않음.

## AI 기능 2: 프로젝트 분석
- 입력: 프로젝트 목표, 마감일, 완료·남은 작업, 열린 이슈, 질문.
- 출력: 상황 요약, 상태, 다음 작업 최대 3개, 위험과 대응 최대 3개.
- 가치: 프로젝트 맥락을 다시 작성하지 않고 다음 우선순위 확인.
- 출력 계약: summary(string), status(enum), next_steps(array), risks(array).
- Python에서 구조·필드·우선순위를 검증하고 JS에서 안전하게 표시.

## 실패와 운영 기준
빈 질문은 호출 전 안내. 서버 입력 제한은 질문 1,000자, 작업·이슈 각각 50개, 요청 본문 64KB입니다. 키 누락·401/403·429·네트워크·시간 초과·파싱 오류를 구분하고 안전한 안내만 반환합니다. 인증 헤더·응답 전체·키를 사용자에게 노출하지 않습니다.

분석 중 중복 클릭을 막으며 자동 재요청은 하지 않습니다. 과금과 사용 한도는 제공자 설정에서 관리합니다. 공개 API의 분산 요청 제한과 실제 사용자 인증은 향후 운영 고도화 범위입니다.

## 구현 범위
순수 HTML/CSS/JS + Vercel Python으로 구현합니다. 데이터는 localStorage에 저장되며 실제 회원 인증·기기 동기화는 범위에 포함하지 않습니다. 실제 계정 비밀번호를 사용하는 서비스를 표방하지 않습니다.

2주 일정 배치는 규칙 기반 기능입니다. Canvas는 선택 기능이고 AI 호출과 분리합니다.

## 성공 기준
동료가 공개 URL에서 데모로 진입하고, 3개 이상의 페이지를 이동하며, 입력한 목표와 질문에 대해 실제 API 결과를 확인할 수 있어야 합니다. 데스크톱과 모바일에서 핵심 입력·버튼·결과를 읽을 수 있어야 합니다.
