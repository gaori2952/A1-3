# AI 코딩 도구 대화 발췌

도구: Codex. 아래는 이 프로젝트 작업에서 사용자가 실제로 입력한 메시지의 발췌입니다. 전체 대화의 일부이며, 각 요청 아래의 구현 설명은 변경 내용을 요약한 것입니다. API 키와 Canvas 토큰은 포함하지 않았습니다.

## 1. 기존 결과의 문제 발견

> 이거 너무 그대로 나와있는거 아니야?

사용자는 아래 스크린샷을 첨부해 고정 작업이 반복되고 체크박스·제목·설명이 붙어 보이는 문제를 지적했습니다.

![개선 전 추천 UI — 사용자가 첨부한 원본](screenshots/starter-before.png)

수정: 목표를 실제 AI API에 전달하고, 제목·우선순위·이유를 구분하는 카드로 변경했습니다.

## 2. 추천 기능의 목적 변경

> 그리고 저걸 시작할 때 ai가 어떤 공부를 할 지 추천해주는게 아니라 일정을 추천해주도록 해줘

수정: 목표와 마감일로 날짜·소요 시간을 제안하고, 선택한 날짜를 작업 예정일에 저장하도록 변경했습니다.

![수정 후 실제 일정 추천](screenshots/ai-schedule.jpg)

## 3. Canvas 조회 문제 해결

> 불러오게 하려니까 과목이 너무 많대 .
> 이번 학기 과목들만 불러올 수 있도록 해줘

원인: 오래된 과목도 active 상태로 반환될 수 있는데 학기 필터 없이 과목 수 제한을 적용했습니다. 수정: term 정보와 학기 날짜로 선택한 학기의 과목을 먼저 선별한 뒤 과제 API를 호출했습니다. 과거 과목 60개와 이번 학기 과목 1개를 반환하는 mock 테스트로 과제 호출이 이번 학기에만 이루어지는지 확인했습니다.
